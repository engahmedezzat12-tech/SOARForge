# SOARForge User Guide

## Standard workflow
1. Select SOAR platform.
2. Select a predefined template or build a custom playbook.
3. Review entities, enrichment, scoring, actions, fallback, testing, and approval.
4. Open Export Center.
5. Review Export Readiness and Threat Coverage.
6. Review SOARForge Intelligence Center.
7. Check Knowledge Update status.
8. Download platform export and Customer Delivery Pack.
9. Record tenant validation outcomes after non-production testing.

## Key concepts
- Design maturity: quality of generated workflow, documentation, and threat coverage.
- Runtime certification: customer tenant validation of connector UUIDs, permissions, action names, and UAT evidence.
- Review Recommended: a template should be reviewed due to a knowledge update or unresolved validation item.
