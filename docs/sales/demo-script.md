# SOARForge Demo Script

## Demo goal
Show that SOARForge is not a static playbook generator. It analyzes the playbook, understands threat coverage, validates platform readiness, produces an intelligence review, and generates a customer-ready delivery pack.

## Suggested flow
1. Open SOARForge.
2. Select FortiSOAR.
3. Choose Ransomware Auto Containment.
4. Walk through the wizard quickly.
5. Open Export Center.
6. Show Export Readiness.
7. Show Threat Coverage.
8. Open SOARForge Intelligence Center.
9. Show What SOARForge Analyzed.
10. Show Action Risk Matrix.
11. Show Tenant Validation Checklist.
12. Show Knowledge Update Center.
13. Download Customer Delivery Pack.
14. Open Admin Console `/admin` to show production foundation.
15. Explain next production step: real FortiSOAR tenant validation.

## Closing message
SOARForge separates design maturity from runtime certification. It generates the playbook package and provides the validation plan required to safely activate it in the customer tenant.
